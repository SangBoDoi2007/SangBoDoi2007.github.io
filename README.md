## Core Capabilities of Cryo (`com.astvn.cryo`)

1. **Game Render Resolution (`30%–100%`, `5%` steps):**
   - **Game Buffer Mode (Android 13+):** Uses Android's native Game Mode downscaling (`cmd game downscale`) so only the selected game renders at a lower resolution while system UI and overlays remain sharp.
   - **Fullscreen Mode (`wm size`) + Resolution Lock:** Changes display resolution while a selected game is on screen, or keeps it locked outside games for titles that read screen bounds only at startup.
2. **4-Level Background App Freezer & Focus Mode:**
   - **Light (`L1`) · Medium (`L2`) · Strong (`L3`) · Extreme (`L4`)** background package control via Shizuku.
   - **Focus Mode:** Automatically freezes unpinned background apps when a chosen game comes to the screen and unfreezes them upon exit.
3. **Real-Time FPS Meter & Floating Monitor:**
   - Displays FPS, CPU/GPU load, free RAM, and CPU/GPU/battery temperature over games. Values a device does not expose are hidden rather than guessed; FPS and CPU/GPU load require Shizuku.
4. **Game Mode Switches & Session Reports:**
   - **AFK Black Screen (`0%` brightness overlay, double-tap to wake)**, **60Hz Refresh Rate Lock**, **Do Not Disturb**, **Low-Latency Wi-Fi (Android 10+)**, and post-session telemetry reports with `100%` reversible `SystemStateGuard` protection.
